# Public repository: confidentiality and privacy

This repository is an educational example, not a public record of any individual's job search.

- Never commit real CVs, applications, recruiter correspondence, client details, contracts, internal metrics, scoring sheets, offers, or selection feedback.
- Renaming employers does not safely anonymize real sequences of job titles, dates, and interview stages. The current demonstration uses invented companies, roles, and dates in 2032.
- Keep populated profile files, opportunity runs, SQLite files, dashboard overrides, real process dates, and real generated HTML outside version control.
- Inspect visible pages AND embedded JSON, screenshots, assets, linked datasets, and previous versions before publishing.
- Deleting or updating a file on the current branch does not remove it from Git history, caches or clones.
- Run `python3 scripts/check_public_snapshot.py` before publishing. The workflow checks structural mistakes; it does not make legal judgments or replace a review of employer and client agreements.

The framework's real-world calibration belongs in a separate private evidence ledger. Use independent fictional examples for public demos.
