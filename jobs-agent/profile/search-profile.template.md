## Hard gates — any failure stops the process, no score needed

1. **Salary floor: [amount]/month base cash.** Not base-plus-illiquid-equity. Clearing only at the very top of a published band = conditional pass at best. If a band tops out below the floor, it is a fail regardless of how good the role is.
2. **Geography: [where you can work].** State what is workable and what is not. Quantified travel above [N] days/year is a sustainability warning, not an automatic fail; "regular / sometimes more" unquantified is a flag to resolve.
3. **Role is real, authorized, live, and genuinely open to an external hire.** A public posting is not required — executive searches count. Fails: speculative interest, pipeline-shaping, unfunded roles, searches where an internal or preselected candidate effectively owns the seat.
4. **No dealbreakers.** Ethical, reputational or structural.

## Standing principles

- **A thin board is not evidence that rejected options have become better.** If a role was scored and passed, it stays passed unless new evidence materially changes the score.
- **Rapport is weak evidence of structural fit.**
- **Warm paths are necessary but not sufficient — and a contact is not an advocate.** A contact forwards a CV; an advocate tells the hiring team *why* a non-obvious background fits. Only advocacy gets an analogy heard, and even advocacy does not overcome a missing selection-critical requirement.
- **Rejections update candidate-fit calibration only.** They are evidence about how you are read, not about the environment — unless the process revealed new organizational evidence.
- **Three different questions, never merged.** Organizational fit: would I thrive there? Asymmetry: would I create unusual value once hired? Candidate fit: will they pick me?
- Score when rested, not depleted. State changes which explanations feel obvious.
